# Spaz Altor — Rediseño E-commerce & Sistema de Diseño

Tienda en línea de ropa deportiva de alto rendimiento para **Spaz Altor** (Medellín, Colombia), diseñada bajo la línea estética **Editorial Athletic Studio**.

## Tecnologías

- **React 18** + **TypeScript 5**
- **Vite 5**
- **Tailwind CSS 3.4**
- **Lucide Icons**

## Ejecución local

```bash
npm install
npm run dev
```

Para generar la compilación de producción:

```bash
npm run build
```
